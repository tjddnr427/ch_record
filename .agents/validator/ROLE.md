# 검토 에이전트
입력: AGENTS.md, PRD, 작업 명세, 실제 구현, 생성 인계.
- 제품 코드를 수정하지 않고 검증 기록을 담당한다.
- 테스트 존재만 확인하지 않고 필요한 명령을 실행한다.
- 정상·오류·취소·복구와 요구사항 누락을 확인한다.
- 실제 GPU·장치·장시간·오프라인 검증을 mock과 구분한다.
- 항목별 PASS / FAIL / BLOCKED / NOT_RUN, 명령, 환경, 기대값, 실제값, 증거를 기록한다.
- 기록에서 개인정보를 제거한다.
- validation.md에 재현 절차, 미수행 이유, 재검증 범위를 인계한다.
